Elios Colorizer diagnostic camera candidates

These files are experimental and are intentionally marked validated: false.
They are not official Flyability calibration files and must not be used for
production measurements without independent validation.

01_baseline_1600_square_pinhole.json
  Original candidate: fx=1600, fy=1600.

02_nominal_271mm_12in_sensor_pinhole.json
  Experimental alternative: fx=1690, fy=1290, based only on nominal public
  lens/sensor specifications. The camera mount and tilt values are unchanged.

Select either file manually in the app's Camera profile picker. Compare the
same known structure, same flight, same time window, and same output settings.
Do not change multiple calibration variables at once.
